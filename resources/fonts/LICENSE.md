# Fonts

**Roboto-Medium.ttf** — Christian Robertson, Apache License 2.0.
https://fonts.google.com/specimen/Roboto

Taken from ImGui's `misc/fonts/`, which is already a dependency of this project,
so the license was settled before it was copied here. Medium weight rather than
Regular on purpose: HUD text sits over arbitrary game geometry and the heavier
stem survives a bright background without an outline pass.
